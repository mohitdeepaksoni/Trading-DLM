# Trading-DLM — deep-learning trading built on the Agora equilibrium engine

Research folder (created 2026-09-05) for a **financial-trading deep-learning model** that can buy/sell shares, ETFs, futures and crypto on **any market**, built to be *unique* (equilibrium-anchored, self-supervised on a no-arbitrage + market-clearing residual, with the macro CGE from `../Mathemetics-DLM` as a structural prior) and *shareable* (open engine + honest-evaluation benchmark). Working name: **Emporion**.

**Honest framing:** a real, certified edge looks like Sharpe 0.6–1.2 after costs and doubles capital every 5–7 years. The engine's job is to find such an edge without fooling you; the guide's job is to keep you solvent long enough for it to compound.
