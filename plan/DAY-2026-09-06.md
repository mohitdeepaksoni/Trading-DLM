# Day plan — 2026-09-06: stand up the deep-learning core (P4 v0)

*Goal for the day: by evening, Emporion has a real deep-learning model — the residual-trained,
equilibrium-anchored net of doc 04/07 — trained on synthetic market states with tests green, and
fitted once on real data with rungs 4 and 5 of the ablation ladder recorded in the ledger. The
structural prior was validated yesterday (P3 step 1); today builds the machine that uses it.*

Machine: Brev `emporion` (A10G). Start with `brev start emporion`; code syncs from `Trading-DLM/`.

## Block A (09:00–11:00) — the model, written and unit-tested (CPU)
`emporion/models/`
1. **Investor types** (`investors.py`): four stylised types with calibrated parameters — mandated/index (must hold cap-weights, demand elasticity ≈ 0.2), active CRRA (risk aversion γ), leveraged (borrowing cap), retail/prospect (loss aversion). Each returns demand `x_h(p; wealth, beliefs, constraints)`.
2. **Clearing model R2** (`clearing.py`): subclass of Agora's `ces_exchange` with assets as goods; `z(p) = Σ_h x_h(p) − supply`; Walras' law and degree-0 homogeneity unit-tested exactly as Agora does.
3. **Structural kernel R1** (`kernel.py`): `M = Σ_h ω_h β_h u'_h(c_{t+1})/u'_h(c_t)` from the same investors, times a penalised neural correction `exp(δ_θ)`; hard projection `E_t[M] = 1/R_f` as a layer; moment residuals against a fixed test-function bank (lagged returns, characteristics, Agora `dlogPX` shock features) plus a small learned adversary.
4. **Encoder** (`emporion/nets/`): per-asset temporal encoder (own K-line tokenizer over 60–250 bars + depth-3 truncated signatures) → Set Transformer over assets with sector edges as attention bias → heads: investor-state latent (clamped to a filter band), `p̂`, conformal score, 4-channel attribution. Reuses Agora `nets/mlp.py`, `nets/moe.py`, `core/device.py`. Target 20–50 M params for v0.
**Exit:** 10+ new tests green (identities, shapes, projection, no-look-ahead of the encoder).

## Block B (11:00–13:30) — training loop on synthetic states (GPU)
`emporion/solvers/`
1. **Synthetic market sampler**: distributions of markets (N∈[20,200] assets, cash-flow processes, investor endowments/wealth shares, shock features from Agora-style draws) — the collocation-point trick.
2. **Residual trainer**: loss = R1 + R2 + LogSumExp tail term + δ-penalty, gradient-magnitude balancing across terms; RAD resampling toward high-residual states; self-adaptive per-state weights; anchor set + parent regularisation hooks (doc 06 §3) present but off for v0.
3. **Hybrid polish + gate**: net warm-start → Agora damped Gauss–Newton on `z(p)=0`; `r_self` (post-polish) and ensemble disagreement (K=3 for v0) → abstain flag; `r_mkt = p − p̂`.
**Exit:** residual falls monotonically; polish reaches ≤1e-9 on ≥95 % of held-out states; p99 `r_self` reported; perf budgets recorded in `benchmarks/`.

## Block C (14:00–16:30) — first fit on real data, through the ledger (GPU)
1. Inputs: US ETF panel (22 + 29 sector ETFs) and NSE-200; features = own encoder on bars + momentum/vol + Agora `dlogPX` event features aligned by date (zero between events); crude investor state (US: index-fund share from ETF AUM; NSE: FII/DII net flows) as the nowcaster placeholder.
2. Train on the residual only (no P&L); evaluate `r_mkt` as a signal: RankIC at h=5/20, abstention rate, hit-rate when acting vs not, conformal-Kelly-sized tilt through `certify()` with costs.
3. **Ablation rungs in one ledger scope**: rung 3 = demand-system-only allocator (investors clear, no kernel), rung 4 = Emporion without Agora features, rung 5 = with Agora features. Momentum (rung 2) already recorded.
**Exit:** three ledger rows with DSR/CPCV/bootstrap; a first honest number for "does the kernel add anything" and "does the prior add anything".

## Guard-rails (from docs 06–08)
